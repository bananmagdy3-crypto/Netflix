# Movie Data Analysis & Visualization 📊🎥

This project focuses on exploring, cleaning, and visualizing movie datasets to uncover insights and hidden trends. By analyzing variables such as movie genres, popularity, release years, and vote averages, we can better understand what makes a movie successful and how ratings evolve over time.

---

## 🚀 Features & Analysis Highlights
* **Distribution of Vote Average:** Analyzing how movie ratings are distributed using histograms and Kernel Density Estimation (KDE).
* **Genre-Based Analysis:** Splitting and exploding multiple genres to find the true relationship between individual film categories and their average ratings.
* **Temporal Trends:** Tracking how movie popularity has changed over the decades.
* **Language vs. Popularity:** Identifying which original languages achieve the highest average popularity.

---

## 🛠️ Libraries & Technologies Used

The project is built entirely in **Python** using the following core libraries:

* **Data Analysis & Manipulation:**
  * `pandas` - For data cleaning, filtering, and exploding multi-genre structures.
  * `numpy` - For numerical operations and handling missing values.

* **Data Visualization:**
  * `matplotlib` - For customized plotting, layouts, and figure structures.
  * `seaborn` - For high-level, modern statistical visualizations (box plots, bar charts, line plots, and distribution curves).
